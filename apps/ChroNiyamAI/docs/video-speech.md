# ChroNiyam AI: Three-Minute Video Speech

## 0:00-0:15 | App And Technology Introduction

ChroNiyam AI is a conversational time-management and task-planning web app. It combines an AI planning assistant with the Eisenhower Matrix and a live schedule board.

The app is built with React, TypeScript, and Vite. It uses the OpenAI API for task understanding, browser speech recognition for voice input, browser speech synthesis for voice replies, and a Vercel serverless function to protect the production API key.

## 0:15-0:50 | Problem Statement

Modern work is rarely difficult because there is nothing to do. The real problem is having too many tasks, unclear priorities, competing deadlines, and limited time.

Important work often gets postponed because urgent requests take over. People also underestimate how long tasks will take, overbook their day, and forget to leave enough time for rest and personal commitments.

A simple task list shows what needs to be done, but it does not always help decide what matters most or whether the plan is realistic.

## 0:50-1:35 | How ChroNiyam AI Solves It

ChroNiyam AI combines conversational task planning with the Eisenhower Matrix and schedule capacity checks.

Users can describe their tasks naturally by typing or speaking. The AI identifies the task, classifies it into one of four planning areas, and helps clarify missing details such as the start date and estimated duration.

The four areas are Do First, Schedule, Delegate, and Eliminate. This separates urgent work from important work and helps users protect time for meaningful progress.

The app also checks available hours, sleep time, task duration, and schedule conflicts. It can suggest a realistic duration or an available time slot. Users can edit tasks directly, move them between quadrants, and finalize the plan when the details are confirmed.

Voice replies are optional. Users can turn them on, choose a voice tone, and adjust playback speed from the voice settings menu.

## 1:35-2:55 | UI Demonstration

First, show the Chroniyam AI welcome screen. Select a planning window such as a day, week, month, or custom number of days, then start planning.

Next, point out the fixed header with the Chroniyam AI name, official logo, and help button. Open the help carousel to show the product overview, the planning workflow, the four matrix areas, and practical planning guidance.

Now show the full planning board. The planner displays the selected date range, available planning information, and the task quadrants.

Click the floating Ask AI button to open the chat window. Type a few tasks, such as preparing a presentation, replying to an important email, and planning a workout. The AI responds and the tasks appear on the board.

Open the AI settings. Adjust the sarcasm level if a more playful planning style is preferred. Use the speaker icon to enable voice replies. Open the gear menu to select a tone, choose a playback speed, and use the Test button.

Return to the task board. Open a task to edit its title, date, time, or duration. Drag a task to another quadrant when its priority changes. Show how warnings identify missing information, conflicts, or a schedule that exceeds available capacity.

Finally, click Clean to clear all tasks while keeping the planning settings, or click Finalize Plan when the schedule is ready. The Start Over action is available when the user wants to reset the entire planning session.

## 2:55-3:00 | Closing

ChroNiyam AI turns a scattered list of responsibilities into a practical plan. It helps users prioritize clearly, use their time realistically, and make steady progress without ignoring balance.
