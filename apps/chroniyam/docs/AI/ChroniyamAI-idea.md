# ChroNiyam AI

> **Speak your thoughts. Organize your priorities.**

## Existing Project and Hackathon Enhancement

ChroNiyam is my original productivity application, designed, developed, and shipped before this hackathon. The existing app is a working Eisenhower Matrix task manager with four priority quadrants, calendar views, recurring tasks, hour estimates, capacity validation, and weekly planning.

- **Live application:** [rikampalkar.github.io/ChroNiyam](https://rikampalkar.github.io/ChroNiyam)
- **Canonical source code:** [github.com/RikamPalkar/rikampalkar.github.io](https://github.com/RikamPalkar/rikampalkar.github.io/tree/main/apps/chroniyam)

The hackathon contribution is the **ChroNiyam AI layer built on top of this existing foundation**. It adds voice input, AI-powered task extraction, Eisenhower Matrix classification, due-date detection, effort estimation, and explainable reasoning. The existing task management and allocation system remains the foundation; the AI feature provides a faster and more intelligent way to create and prioritize tasks.

## Description

ChroNiyam AI is a voice-powered task triage assistant that turns an unstructured brain dump into a clear, actionable plan. Users can speak naturally about everything they need to do, while AI transcribes the input, separates it into individual tasks, estimates the effort, identifies due dates, and places each task in the appropriate Eisenhower Matrix quadrant.

Before anything is added, users can review and edit the AI-generated tasks, change their priorities, and confirm the final plan. Each classification includes a simple explanation so users understand why a task was marked as urgent, important, scheduled, delegated, or low priority. Confirmed tasks then use ChroNiyam's existing calendar and hours-allocation features.

ChroNiyam AI combines voice interaction, explainable AI, and practical time management to help people move from scattered thoughts to focused action with less friction.
