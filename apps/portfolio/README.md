### 🎯 Tic-Tac-Toe with Minimax Algorithm

One of my passion projects is an intelligent **Tic-Tac-Toe game** built with React that implements the **Minimax algorithm** for AI opponent.

**Repository**: [rikampalkar.github.io.TicTacToe](https://github.com/RikamPalkar/rikampalkar.github.io.TicTacToe)

#### 🧠 What is Minimax Algorithm?

The **Minimax algorithm** is a decision-making algorithm used in game theory and artificial intelligence, particularly for two-player, zero-sum games like Tic-Tac-Toe, Chess, and Checkers.

**How it works:**

1. **Recursive Evaluation**: The algorithm explores all possible game states by simulating every possible move
2. **Maximizer & Minimizer**: 
   - **Maximizer** (AI) tries to maximize its score
   - **Minimizer** (Human) tries to minimize the AI's score
3. **Backtracking**: Starting from terminal states (win/loss/draw), it backtracks to choose the optimal move
4. **Score Assignment**:
   - AI Win: `+10`
   - Human Win: `-10`
   - Draw: `0`

**In Tic-Tac-Toe:**
- The AI evaluates every possible move
- Simulates opponent's best responses
- Chooses the move that leads to the best outcome
- Makes it virtually **unbeatable**!

**Why it matters:**
The Minimax algorithm teaches fundamental concepts in:
- Recursion and tree traversal
- Game state evaluation
- Decision-making under uncertainty
- Optimization strategies

This project demonstrates practical application of computer science theory in building intelligent systems.
